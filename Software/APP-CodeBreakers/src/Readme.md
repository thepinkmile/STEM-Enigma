# Code Breakers

This application is being designed and built initially for Windows desktop, but with the flexibility to provide support for other platforms.

This project should use/have the following:
- Unit tests covering all "good" and "bad" inputs
- Versioning using GitHub Version Tool
- Git Flow branching strategy
- Mutation testing (if possible)
- 3D Model Viewing and "Explosions"
- Highlighting of electronic paths during encode/decode cycles
- An area of information about the history
- Where defined, code style rules should be implemented and verified during builds
